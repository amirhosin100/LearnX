# سایت آموزشی LearnX
## ساخته شده با django
## همچنین با DRF
لینک مشاهده ی سایت
[LearnX](https://amirhossein404.pythonanywhere.com) \
این سایت دارای app  های مختاف است 
### user
در این app مدل های مربوط به کاربران ایجاد و ساخته شده است که teacher و bloger هستند
هر کاربر می تواند هم blogger و هم teacher باشد 
در قسمت template این app صفحاتی مثل صفحه ی اصلی و صفحه درباره ی من ایجاد شده است
همچین سیستم ورود با گوگل ایجاد شده است که کاربر می تواند با آن احراز هویت کند و همچنین اگر اکانت او تصویری داشته باشد این تصویر ذخیره و در قسمت profile او نمایش داده می شود
### learn
در این app مدل های مربوط به آموزش ها ساخته شده است مثل خود آموزش ,سرفصل های آموزش, فیلم های آموزش, و امتیاز برای هر فیلم
هر آموزش یک قسمت توضیحات دارد که با استفاده از CKeditor-5 می توان توضیحات زیبا تری را ایجاد کرد که فقط یک متن ساده نباشد و دارای متن bold , list و ... باشد
