# سایت آموزشی LearnX
## ساخته شده با django
لینک مشاهده ی سایت
[LearnX](https://amirhossein404.pythonanywhere.com) 


### قابلیت ها و تکنلوژی های استفاده شده در این پروژه
+ لاگین و ثبت نام کاربران به دو صورت ورود با **گوگل** و روش معمولی
+ ساخت **api** برای پروژه
+ بخش سبد خرید و استفاده از **session** در آن
+ ایجاد user ها با سطح دسترسی های متفاوت مثل teacher , bloger
+ قسمت کامنت برای هر دوره و هر مقاله
+ استفاده کردن از *ویرایشگر متن* برای قسمت هایی مثل توضیحات آموزش , مقاله , توضیحات فیلم برای زیباتر شدن آن
+ افزودن قابلیت *کد تخفیف* برای پروژه
+ قسمت لایک مقاله
+ قسمت پرسش سوال برای هر ویدئو دوره و همچین امتیاز دهی از 1 تا 5
+ قسمت تیکت ها , مشخص کردن نوع تیکت و همچنین قابلیت بستن تیکت
+ ذخیره تراکنش ها پس از خرید دوره توسط کاربر
+ ایجاد قسمت پروفایل برای teacher و bloger
+ پیاده سازی ajax برای سبدخرید, قسمت کامنت ها, لایک مقالات و...
